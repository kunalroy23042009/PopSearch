FAQ

Got questions?

What data sources does it use?

YouTube Data API v3, Reddit (via PRAW + RSS), Google Trends (via pytrends), Twitter/X API v2, Twitch Helix API, Hacker News Firebase API, and RSS feeds (TechCrunch, The Verge, Product Hunt, YouTube Blog). Google Gemini for AI analysis. All sources are free-tier accessible.

How accurate is the niche profiling?

The AI analyzes your channel title, description, subscriber count, recent video titles, engagement metrics, and upload frequency to generate a niche profile. The more content you have, the more accurate it is.

Can I use it without API keys?

No — you need at minimum a YouTube Data API key and a Gemini API key. Both have free tiers. Check .env.example for setup instructions.

Is my data stored?

Analysis results are cached locally for 24 hours to avoid redundant API calls. No data is sent to third parties. On the SaaS version, your account data is stored securely.
